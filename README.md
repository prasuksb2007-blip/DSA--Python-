# Data Structures and Algorithms (DSA) in Python

Welcome to the **DSA--Python-** repository! This project serves as a comprehensive resource for learning, practicing, and implementing advanced **Data Structures and Algorithms** using Python based on the course syllabus.

---

## 📋 Course Prerequisites
1. **Proficiency in basic data structures** such as arrays, linked lists, stacks, and queues.
2. **Understanding of fundamental algorithms** like sorting and searching.
3. **Knowledge of object-oriented programming** concepts and implementation.
4. **Familiarity with computational complexity analysis** and Big O notation.
5. **Basic understanding of discrete mathematics**, including sets, relations, and graphs.
6. **Experience with Python** and the ability to implement algorithms and data structures.

---

## 📖 Course Description
Throughout this course, students explore the theoretical foundations and practical applications of non-linear structures and advanced algorithms, focusing on efficient implementation and problem-solving. Key topics include:
* Trees, graphs, hashing, multiway search trees, and file organization techniques.
* Advanced tree structures such as AVL trees, B-trees, and Red-Black trees.
* Graph traversal algorithms (DFS, BFS) and shortest path/minimum spanning tree algorithms.
* Static, dynamic, and advanced hashing techniques (open addressing, chaining, Bloom filters).
* File organization strategies including sequential, direct access, and indexed sequential files.

---

## 🎯 Course Objectives
* Provide the foundations of the practical implementation and usage of non-linear data structures and algorithms.
* Develop competent programmers capable of implementing advanced data structures for complex real-world problems.
* Examine hashing algorithms for rapid data retrieval and factors influencing performance.
* Build awareness of modern searching and indexing concepts.
* Demonstrate different file organization techniques.

---

## 🎓 Course Outcomes
Upon completing this course, you will be able to:
1. **Understand** non-linear data structures such as trees and graphs.
2. **Select and apply** appropriate non-linear data structures and algorithms for real-world scenarios.
3. **Define complexity goals** and benefits of robust hashing schemes.
4. **Recognize** efficient indexing and multiway search techniques for data manipulation.
5. **Recall** modern file organization concepts and primitive operations.

## 📁 Syllabus & Repository Structure

### Unit I: Trees
* **Theory**: Basic terminology, general trees, sequential and linked representation, Binary Tree properties, conversions, traversals (in-order, pre-order, post-order, level-wise, DFS, BFS), Binary Search Tree (BST) operations, In-order Threaded Binary Tree operations.
* **PBL / Case Study**: Expression tree evaluation, Huffman’s coding.
* **Files**:
  - [x] Single Linked List (`single_linked_list.py`)
  - [x] Stack (`stack.py`)
  - [x] Queue (`queue.py`)
  - [x] Binary Tree (`binary_tree.py`)

### Unit II: Graphs
* **Theory**: Adjacency Matrix, Adjacency List, Adjacency Multi-List, Inverse Adjacency List, Depth-First & Breadth-First Traversals, Topological Ordering, Greedy Algorithms (Prim's, Kruskal's MST, Dijkstra's Shortest Path).
* **PBL / Case Study**: Data structures used in Webgraph and Google Maps.
* **Files**:
  - [ ] Graph Representations *(Upcoming)*

* **Theory**: Static Hashing, Hash Functions, Collision Resolution (Chaining, Linear/Quadratic Probing, Double Hashing), Dynamic Resizing (Load Factor, Rehashing), Dynamic Hashing (Directories/Directory-less), Advanced Techniques (Cuckoo Hashing, Hopscotch Hashing, Robin Hood Hashing, Bloom Filters).
* **PBL / Case Study**: Optimization of employee record management using Hash Tables.
